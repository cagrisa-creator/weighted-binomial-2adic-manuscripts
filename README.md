# Weighted binomial sums over the 2-adic integers

César Augusto Grisa · Independent Researcher · 17 November 2026

This archive contains two research manuscripts, their editable LaTeX sources, and the arithmetic checks used to reproduce sample cases.

| Manuscript | Files | Zenodo DOI |
|---|---|---|
| Images and fiber multiplicities of a weighted Delannoy family over the 2-adic integers | [PDF](Grisa_Delannoy_Fibers_CMB.pdf) · [LaTeX](Grisa_Delannoy_Fibers_CMB.tex) | [10.5281/zenodo.24326991](https://doi.org/10.5281/zenodo.24326991) |
| Injectivity of weighted cubic binomial sums on the 2-adic integers | [PDF](Grisa_Cubic_Binomial_Sums_OJAC.pdf) · [LaTeX](Grisa_Cubic_Binomial_Sums_OJAC.tex) | [10.5281/zenodo.24327011](https://doi.org/10.5281/zenodo.24327011) |

The quadratic manuscript follows the structural guidelines of the Canadian Mathematical Bulletin using a standard LaTeX class. The cubic manuscript is a standalone PDF prepared for the Online Journal of Analytic Combinatorics.

Run `python verificar.py` with Python 3. The script evaluates the binomial sums at finite precision, checks the reported derivative residues, and reproduces `verificacao.json`. The finite computations complement the proofs in the manuscripts.

The JSON metadata files describe the two manuscripts for archiving. The Zenodo records also provide the LaTeX source and verification code for each preprint.
